# Gospel Games

Gospel Games is a faith-based party game platform built for youth groups, Christian fellowships, and social gatherings. It combines fast-paced party game mechanics with scripture themes, packaged in a tactile 3D Claymorphism design system.

## Game Library

### Active Games
- **The Altar**: Fast-paced card shedding game with action cards and "Amen!" callouts when down to one card.
- **Biblical Banter**: Prompt submission and voting battles where the best comedic and scriptural responses win points.
- **The Scribe**: Audio-driven scripture spelling bee powered by neural TTS with fuzzy scoring and dynamic difficulty tiers.
- **Blind Rankings**: Players rank biblical items or scenarios one at a time without knowing upcoming choices.
- **One Accord**: Cooperative game where the room attempts to converge on identical answers (Acts 1:14).
- **Pick-A-Side**: Rapid scripture discernment quiz (Old vs. New Testament, Truth vs. Twist) with simultaneous group reveals.
- **Pentecost (The Outpouring)**: Real-time scripture typing race with streak combos and particle effects.
- **Crossroads & Confessions**: Fellowship modules combining theological dilemmas with testimony sharing using Grace Tokens.
- **Tick Or Ick**: Swipe-based consensus game for evaluating character traits and social scenarios.
- **Great Commission**: Interactive outreach prompts and witnessing scenarios designed for youth ministry discussions.

## Technical Architecture & Design

- **Tactile Claymorphism**: Soft 3D neumorphic depth, Fredoka typography, and continuous ambient backgrounds.
- **Multiplayer & Networking**: Real-time room orchestration using Firebase Realtime Database (presence and game sync), Firestore (content and profiles), and Supabase (telemetry and bug reporting).
- **Instant Offline & Local Caching**: Instant session generation and local asset caching ensure smooth gameplay without network hiccups.
